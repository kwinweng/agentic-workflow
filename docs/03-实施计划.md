# 03 · 实施计划

> 前置：[01-开源方案调研](01-开源方案调研.md) · [02-架构设计](02-架构设计.md)
> 原则：每个里程碑独立可用、可验收，尽早跑通端到端最小链路。

## M1 · 转写核心（CLI 可用）——预计 3~5 天

**范围**：链接解析器 + 逐字稿获取（字幕直抓 + whisper 兜底），先以 CLI 形态交付。

- [ ] 项目脚手架：FastAPI 工程、配置加载、SQLite 迁移
- [ ] `resolver`：BV / b23.tv 短链 / 分 P / 合集展开
- [ ] `transcriber` 路线 A：字幕列表接口（wbi 签名 + SESSDATA）、CC/AI 字幕下载与解析、限频
- [ ] `transcriber` 路线 B：BBDown 仅音频下载 → faster-whisper 转写（引擎接口可插拔）
- [ ] 统一 Transcript 结构，产出 `transcript.md` / `transcript.json` 落盘
- [ ] CLI：`python -m pipeline.cli <url...>` 批量跑

**验收**：给 3 条链接（1 条有 CC 字幕、1 条只有 AI 字幕、1 条无字幕），
均能产出带时间戳逐字稿，且前两条不下载任何音视频。

## M2 · 任务队列 + 管理后台——预计 4~6 天

**范围**：服务化 + 后台第一期页面。

- [ ] 任务表即队列的 asyncio worker（重启恢复、失败重试）
- [ ] REST API（提交/列表/详情/重试）
- [ ] 后台页面：任务提交（批量贴链接）、任务列表、成果详情（逐字稿预览）
- [ ] 审核队列页骨架（M3 出草稿后启用：草稿列表/预览/采纳/退回/丢弃）

**验收**：后台粘贴 5 条链接批量提交，可看进度，能预览逐字稿。

## M3 · AI 知识提炼——预计 3~5 天

**范围**：`distiller` 两段式（清洗 → **Agent Skills 草稿**）+ 审核流 + 技能库。

- [ ] OpenAI 兼容 LLM 客户端（DeepSeek/Qwen 配置切换）、长文本分块
- [ ] 清洗 prompt 与 `cleaned.md`
- [ ] `project-context.md` 项目背景机制 + skill 草稿生成 prompt
      （SKILL.md 格式见 [产品方案定稿](superpowers/specs/2026-07-08-knowledge-skills-design.md) §3）
- [ ] `knowledge-base/drafts/` → 审核 → `knowledge-base/skills/` 的状态流转与 `INDEX.md` 索引
- [ ] 后台审核队列页启用（采纳/退回/丢弃）

**验收**：对一条真实课程视频跑全链路，产出与项目相关的 skill 草稿（含触发 description
与时间戳溯源）；后台采纳后草稿移入 `skills/` 且可被 Claude Code 作为技能加载。

## M4 · 飞书机器人——预计 3~4 天

**范围**：飞书自建应用接入（长连接模式）。

- [ ] 飞书开放平台建应用、开通机器人与 `im.message.receive_v1` 权限（需要你提供企业内创建权限）
- [ ] `lark-oapi` 长连接接入、消息中提取 B 站链接、事件去重
- [ ] 受理即回执；完成后回复卡片（标题/来源/摘要/skill 草稿数/落盘路径）
- [ ] 卡片内「采纳/退回」审核按钮（与后台审核队列同一状态机）
- [ ] 群聊 @ 与私聊两种场景

**验收**：飞书私聊丢一条 B 站链接，收到回执与完成卡片，产物出现在服务器知识库目录。

## M5 · 图文稿 + 打磨与部署——预计 3~4 天

- [ ] `snapshotter`：勾选"图文稿"时下载视频流 + ffmpeg 按段落抽帧 → `article.md` 图文稿（自 M2 后置至此）
- [ ] Docker Compose 一键部署（内置 ffmpeg/BBDown，whisper 模型预热）
- [ ] 失败告警（飞书通知）、日志、简单鉴权（后台访问口令）
- [ ] 使用文档

## 需要你准备的东西（按里程碑）

| 里程碑 | 需要 |
| --- | --- |
| M1 | 一个 B 站普通账号的 `SESSDATA`（浏览器登录后从 Cookie 复制） |
| M3 | DeepSeek 或 Qwen 的 API Key；一段"项目背景描述"（技术栈/业务/痛点，200~500 字，用于 `project-context.md`） |
| M4 | 飞书企业内创建自建应用的权限（App ID / App Secret） |
| M5 | 部署服务器（建议 4C8G+，跑 whisper 兜底用） |
