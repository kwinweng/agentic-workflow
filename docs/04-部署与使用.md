# 04 · 部署与使用

## 快速开始（Docker，推荐）

```bash
cp .env.example .env      # 填入 BILI_SESSDATA、LLM_API_KEY 等
docker compose up -d      # 管理后台 + worker → http://localhost:8000/admin
docker compose --profile feishu up -d   # 配好飞书凭据后再启动机器人
```

数据全部落在 `./data/`（SQLite + 知识库 + 临时下载），备份该目录即可。

## 源码运行

```bash
uv venv .venv && uv pip install -e ".[dev,asr,feishu]"
# 系统需有 ffmpeg；下载工具二选一：BBDown（推荐）或 pip install yt-dlp（对应 DOWNLOADER 配置）
cp .env.example .env

.venv/bin/uvicorn pipeline.app:app --port 8000     # 管理后台 + worker
.venv/bin/python -m pipeline.feishu_bot            # 飞书机器人（长连接 + 自带 worker）
.venv/bin/python -m pipeline.cli BV1xxx b23.tv/xxx # 免服务直接跑（批量）
```

## 必备配置（.env）

| 变量 | 说明 |
| --- | --- |
| `BILI_SESSDATA` | B 站普通账号 Cookie。浏览器登录 bilibili.com → F12 → Application → Cookies → 复制 `SESSDATA` 值。**没有它抓不到 AI 字幕**，会大量落到慢速的 whisper 兜底 |
| `LLM_API_KEY` / `LLM_BASE_URL` / `LLM_MODEL` | DeepSeek：默认值即可，填 Key。Qwen：`https://dashscope.aliyuncs.com/compatible-mode/v1` + `qwen-plus` |
| `ADMIN_TOKEN` | 后台口令（建议公网部署时必设）。访问时 `?token=xxx` 一次后种 cookie |
| `FEISHU_APP_ID/SECRET` | 飞书开放平台自建应用（见下） |

`project-context.md`（仓库根目录）：写 200~500 字的团队技术栈/业务/痛点描述，
知识提炼的相关性判断全靠它。没有它也能跑，但提炼出的 skill 泛化、confidence 上限 medium。

## 飞书自建应用配置

1. [飞书开放平台](https://open.feishu.cn) → 创建企业自建应用 → 记下 App ID / App Secret
2. 添加**机器人**能力
3. 权限：`im:message`（接收消息）、`im:message:send_as_bot`（发消息）
4. 事件订阅 → 选择**使用长连接接收事件**（无需公网地址）→ 订阅 `im.message.receive_v1`
5. 发布版本并在企业内可用范围生效
6. 把机器人拉进群或直接私聊：丢 B 站链接即可；完成后回卡片，卡片上可直接采纳/退回 skill 草稿

## 使用流程

```
丢链接（飞书 / 后台 / CLI）
  → 逐字稿 knowledge-base/videos/{bvid}-{标题}/transcript.md
  → 清洗稿 cleaned.md + skill 草稿 knowledge-base/drafts/{name}/SKILL.md
  → 审核（后台 /admin/review 或飞书卡片按钮）
  → 采纳后 knowledge-base/skills/{name}/SKILL.md + INDEX.md 索引更新
```

**把技能库接入 AI 编程助手**：在目标项目里
`git submodule add <本仓库> vendor/team-skills`，然后把
`vendor/team-skills/knowledge-base/skills/` 链接/复制到项目的 `.claude/skills/`
（Claude Code）或在 AGENTS.md 中引用（Codex）。

## 运维

- 任务失败自动重试 3 次；最终失败可在后台点「重试」；配置 `FEISHU_ALERT_CHAT_ID`
  可把失败告警发到指定群
- B 站接口风控：默认请求间隔 ≥3s，批量大合集请耐心；SESSDATA 失效表现为
  大量任务落到 whisper 兜底，换号重填即可
- whisper 模型（`WHISPER_MODEL=small/medium/large-v3`）按机器性能选择，
  首次使用自动下载并缓存
