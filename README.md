# B 站视频学习资料 → 专有开发知识库 Pipeline

将 B 站（Bilibili）上的学习课程视频批量转换为文字逐字稿，再经 AI 提炼为可复用的
**专有开发知识库**，服务于团队的开发流程优化。

## 需求概述

1. **批量转写**：输入 B 站视频链接，自动生成文字逐字稿（免费、开源方案）。
2. **两个使用场景**：
   - **飞书入口**：在飞书里丢一个链接，机器人解析出逐字稿并保存到服务器本地知识库，同时在飞书回复摘要。
   - **管理后台**：网页后台粘贴链接（支持批量），生成"图片 + 文字"的图文稿（逐字稿 + 关键帧截图）。
3. **AI 再处理**：对收集到的原始逐字稿做二次加工，提炼出对项目开发有帮助的知识点（知识卡片），沉淀为可复用的团队知识。

## 已确认的技术决策

| 决策点 | 结论 |
| --- | --- |
| 逐字稿获取策略 | **字幕优先 + whisper 兜底**：先抓 B 站现成 CC/AI 字幕，没有字幕才下载音频跑本地 faster-whisper |
| AI 知识提炼 LLM | **国内模型（DeepSeek / Qwen）**，走 OpenAI 兼容接口 |
| 飞书接入方式 | **飞书开放平台自建机器人应用**（事件订阅，推荐长连接模式，无需公网回调地址） |
| 交付节奏 | 本期先交付调研 + 架构设计文档，评审通过后按 [实施计划](docs/03-实施计划.md) 分期开发 |
